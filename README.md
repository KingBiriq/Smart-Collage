# Smart Collage

Next.js web demo: landing website, student preview, admin preview.

Run `npm install`, then `npm run dev`. Build with `npm run build`. Import the GitHub repository into Vercel using Next.js defaults.

Routes: /, /preview, /student, /admin, /api/health.

This is a browser-local demo. Real authentication, payments, Bunny video, encrypted offline downloads and native iOS/Android builds are not implemented in this recovered source. No production credentials or student records are included.
